# XSS_Attack_Lab

⚠️ Lab 7.10: Cross-site Scripting (XSS) Attacks (Zybooks)

This lab demonstrates how attackers can inject malicious JavaScript code into vulnerable websites using reflected and stored XSS techniques. It also covers how to defend against these attacks by sanitizing user input.

🧠 Learning Objectives

--Perform reflected and stored XSS attacks with JavaScript

--Understand the risks of unsanitized input in web applications

--Learn how to mitigate XSS using basic input validation and filtering

🖥️ Environment
VM Used: ZyWin01 (Windows Server 2022)

✅ Tasks Completed
1) Carried out a reflected XSS attack

2) Mitigated the reflected XSS vulnerability

3) Executed a stored XSS attack

4) Prevented the stored XSS using sanitization techniques
